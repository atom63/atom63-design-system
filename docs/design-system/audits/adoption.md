## Runtime coverage

REI Cedar's method: each visible interactive and landmark element on a route counts as system when it or an ancestor carries an `a63-*` class or one of the 611 `data-slot` values the system renders. atom63-vite sets `data-slot` on its own components too, so any `data-slot` would overcount; a system slot name that the app or one of its workspace packages also writes itself counts only with an `a63-*` class (the "Ambiguous slots" column; the names are in adoption.json). "Self" counts only elements that carry the marker themselves, which is stricter: a hand-written button inside a system Card counts as system under the first measure, not the second.
