## Problem

Orchard Ledger makes accounting software for small businesses. Its web and iOS apps were built by separate teams, and the same invoice looked different on each: three greys, two date formats, and buttons of four heights.

## Role

I led the system: the token architecture, the component contracts and the rollout plan, working with one designer and three engineers across both platforms.

## Process

<Steps>
  <Steps.Step title="Audit">Every screen of both apps on one board, grouped by component. 212 variants of 31 components.</Steps.Step>
  <Steps.Step title="Tokens first">One token source for colour, space and type, generated for CSS and Swift.</Steps.Step>
  <Steps.Step title="Contracts">Each component's sizes, variants and states defined once, and checked in both renderers.</Steps.Step>
</Steps>

<Callout type="info">
  The system is built on the Atom63 design system, the same one this portfolio uses.
</Callout>
