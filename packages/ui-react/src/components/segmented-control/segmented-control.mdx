A single-select segmented control — a recessed track with a raised pill that slides to the selected segment. It is a radio group (Base UI RadioGroup): name it with `aria-label` or `aria-labelledby`; Tab enters at the selected segment and the arrow keys move and select. Use Tabs when the choices switch content panels. Driven by an `items` array; the active pill and track read theme-overridden semantics, so the four themes restyle it for free.

## Anatomy

- Root `.a63-SegmentedControl` — `role="radiogroup"`, `data-slot="segmented-control"`, carries `data-size`, `data-variant`, `data-tone`, and takes the group's `aria-label` / `aria-labelledby`.
- Track `.a63-SegmentedControl-track` — the recessed well.
- Item `.a63-SegmentedControl-item` — a segment, `role="radio"`; Base UI stamps `data-checked` on the selected one, `data-disabled` on disabled items.
- Indicator `.a63-SegmentedControl-indicator` — the sliding raised pill, placed by the `--segment-indicator-*` vars the component measures.

## Contract

- **Sizes:** `sm` `md` `lg` (default `md`).
- **Variants:** `icon` (square segments) · `label` (text + optional leading icon). Default `label`.
- **Tones (active pill):** `neutral` (raised surface, default) · `accent` (brand primary). Aligns with the Toggle `tone` axis.
- Per-item `disabled?: boolean`.
- Source of truth: `@atom63/ui-foundation` → `contracts/components/segmented-control.json`.

## Tokens it reads

Each theme sets the `--a63-segment-*` tokens; the recipe falls back to the foundation when a theme leaves one unset.

- Track: `--a63-segment-track-background` (falls back to `--a63-surface-muted`), `--a63-segment-track-border` (`--a63-border-subtle`), `--a63-segment-track-shadow` (`--a63-track-shadow`).
- Selected plate: `--a63-segment-selected-background` (`--a63-surface-overlay`) with `--a63-control-shadow`; accent tone `--a63-segment-primary-background` (`--a63-action-primary`).
- Labels: `--a63-segment-foreground` (`--a63-text-secondary`) at rest, `--a63-segment-hover-foreground` (`--a63-text-primary`) on hover, `--a63-segment-selected-foreground` (`--a63-text-primary`) when selected, `--a63-segment-primary-foreground` (`--a63-action-primary-foreground`) on the accent plate.
- Geometry: the `--a63-control-*` ramp. On a coarse pointer the track grows to `--a63-control-min-target`, because the scrolling track clips hit areas drawn outside it.
