<Title />

A quiet bistate pressable (Base UI Toggle) — stays pressed without borrowing Button chrome. Geometry reuses the `--a63-control-*` ramp; active fill uses `tone`. For a welded segmented bar, use `ToggleGroup`. For a gapped row, compose individual `Toggle`s.

## Anatomy

- Root `.a63-Toggle` — `data-slot="toggle"`, carries `data-size`, `data-tone`; Base UI stamps `data-pressed` / `data-disabled`.
- Content `.a63-Toggle-content` — `data-slot="toggle-content"`, the press-scale wrapper.

## Contract

- **Sizes:** `sm` `md` `lg` (default `md`).
- **Tones (active fill):** `neutral` (the high-emphasis neutral solid, as on a default Button; reverse video in the terminal theme) · `accent` (brand primary) · `subtle` (accent text, no fill).
- Source of truth: `@atom63/ui-foundation` → `contracts/components/toggle.json`.

## Tokens it reads

Geometry from `--a63-control-*`. Pressed fills from `--a63-toggle-*`, falling back to `--a63-action-neutral` and `--a63-action-primary`. In forced-colors mode a pressed toggle takes the system `Highlight` colours. Focus uses `--a63-focus-ring`.
