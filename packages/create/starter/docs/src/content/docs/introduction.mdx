These docs are MDX files in `src/content/docs`. Each file is a page: the file name is its slug,
and its frontmatter sets the title, description, sidebar group and order.

## How the sidebar works

Pages with the same `group` appear together, and `order` sorts them inside the group. The groups
follow the list in `src/content/docs.ts`; new groups come after it.

## Reading straight through

Every page links to the one before and after it, in the same order as the sidebar.
