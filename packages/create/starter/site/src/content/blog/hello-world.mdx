This post is an MDX file in `src/content/blog`. Its file name is the slug, and its frontmatter
sets the title, description and date. Add a file, and it appears on the blog.

## What is set up

- **Components** from `@atom63/ui-react`, styled by recipes that read `--a63-*` tokens.
- **Tailwind** with a theme that maps utilities such as `bg-background` onto the same tokens.
- **MDX** rendered with the `@atom63/mdx` typography, so posts match the rest of the site.
- **Themes and modes** switched from the header; everything follows them.

<Callout type="info">
  Use components from `@atom63/mdx/blocks` in any post. This callout is one of them.
</Callout>
