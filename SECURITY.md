# Security policy

## Supported versions

Atom63 is in public beta. Security fixes land in the latest version on the npm `beta` tag of each
package; older beta versions do not receive fixes.

| Package                 | Supported           |
| ----------------------- | ------------------- |
| `@atom63/styles`        | Latest `beta` only  |
| `@atom63/ui-foundation` | Latest `beta` only  |
| `@atom63/ui-react`      | Latest `beta` only  |
| `Atom63UI` (SwiftPM)    | `main` branch only  |

## Reporting a vulnerability

Do not report a suspected vulnerability in a public issue, discussion, or pull request.

Report it privately through GitHub:
[open a private vulnerability report](https://github.com/atom63/atom63-design-system/security/advisories/new)
(repository **Security** tab → **Report a vulnerability**).

Include:

- the affected package and version;
- a description of the issue and its impact;
- steps or a minimal reproduction; and
- any known mitigation.

## What to expect

Support is best-effort during the beta, and there is no response-time guarantee. The maintainer
will acknowledge the report in the private advisory, agree a disclosure plan with you, and credit
you in the advisory unless you ask not to be named. Please keep the details private until a fix
is released or the disclosure plan says otherwise.
