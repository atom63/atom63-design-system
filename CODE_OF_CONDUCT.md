# Code of Conduct

Atom63 Design System adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone taking part in this project's spaces: issues, pull
requests, discussions, and any other channel where the project is represented.

In short: be respectful and constructive, welcome people of every background and experience
level, focus on what is best for the community, and do not harass, demean, or exclude anyone.

## Reporting

To report behavior that breaks this code of conduct, use the repository's private reporting
channel: [open a private report](https://github.com/atom63/atom63-design-system/security/advisories/new)
and start the title with "Code of conduct". Reports are visible only to the maintainer and are
handled confidentially. You can also use GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature on any comment or issue.

## Enforcement

The maintainer reviews every report and decides on a response following the enforcement guidelines
of the Contributor Covenant: a correction, a warning, a temporary ban, or a permanent ban,
depending on the impact of the behavior.
