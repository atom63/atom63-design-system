# First project

What a new user of a design feedback tool sees right after signing up, before they have any
projects.

- The page explains in one or two sentences what a project is and why they would create one.
- One primary action, "Create your first project", and a secondary way to "Import from Figma".
- Below it, a short checklist of three getting-started steps (create a project, invite a teammate,
  share a link for feedback), each with a one-line explanation. The first step is the current one;
  the others are not done yet.
- A link to a two-minute video tour.
- Pressing "Create your first project" opens a small dialog that asks for a project name and
  creates it. After that, the page shows the new project in a list and the checklist marks the
  first step done.
