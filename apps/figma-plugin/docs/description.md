A token table for your Figma file, from code or from a few choices

Create a token system: pick a brand color, a neutral, a radius, a type scale and a font, and watch a preview card follow. Cipher writes the site template's variables, text styles and effect styles into the file with your choices as the default modes, and keeps every other mode so designs can switch them. Export CSS gives the matching token files for a project started from the template.

Import from CSS: pick or paste the CSS files that hold a project's tokens. Each data-* attribute becomes a collection with its values as modes, light and dark become a Mode collection, aliases stay aliases, and text sizes and shadows become text and effect styles. Preview what changes, apply, and Cipher checks that the file matches the code. Code stays the source of truth: after the CSS changes, ask your coding agent to sync, or import again.
