# MDX blocks

Every block `@atom63/mdx/blocks` exports, with what it is for, a working example and its props. The props tables are read from each block's TypeScript types. For setup and the providers, see [MDX content](/patterns/pattern-mdx).

Inside a provider (`MDXContentProvider`, `DocsMDXContentProvider` or `ArticleMDXContentProvider`), most blocks need no import: the provider's component map registers them. `KeyIdea`, `Compare`, `ImageCompare`, `LayerStack`, `DocExample`, `DocExampleCode` and `DemoConfigPanel` are not in the map; import them from `@atom63/mdx/blocks`. In React, import any block from there.

Look a block up from the terminal with `atom63 api <Block>`, for example `atom63 api KeyIdea`.

A notice beside the text: a tip, a caveat, an error to avoid or a success state. Pick `type` by what the reader should feel; one callout per point.

### ImageCompare

Two images in one frame with a draggable divider. Use it when the visual difference is the point; give both images real `alt` text. The slider loads on demand.

### VideoBlock

A video figure with native controls and an optional caption. A video with speech needs a caption track (`trackSrc`); mark a purely visual loop `captionPolicy="decorative"` instead. With `autoPlay` and no `controls`, it draws its own pause button and stays still under reduced motion.

```mdx
<VideoBlock src="/media/talk.mp4" title="Design tokens talk" trackSrc="/media/talk.en.vtt" />

<VideoBlock
  autoPlay
  captionPolicy="decorative"
  controls={false}
  loop
  muted
  src="/media/loop.mp4"
  title="Theme switching loop"
/>
```

<MdxBlockProps name="VideoBlock" />

### DemoConfigPanel

The controls panel for a `DemoStage`: a popover beside the stage, a sheet on small screens. Put it in `headerEnd` and pass the stage's ref.

```tsx
import { DemoConfigPanel, DemoStage } from '@atom63/mdx/blocks'
import { Switch } from '@atom63/ui-react'
import { useRef, useState } from 'react'

function TunableDemo() {
  const stageRef = useRef<HTMLElement>(null)
  const [dense, setDense] = useState(false)

  return (
    <DemoStage
      ref={stageRef}
      headerEnd={
        <DemoConfigPanel stageRef={stageRef} title="Demo controls">
          <label>
            <Switch checked={dense} onCheckedChange={setDense} /> Dense
          </label>
        </DemoConfigPanel>
      }
    >
      <p>{dense ? 'Dense' : 'Comfortable'}</p>
    </DemoStage>
  )
}
```

## Prose elements

The provider's component map also styles plain Markdown, so most of a page needs no blocks:

| Markdown | Renders as |
|----------|------------|
| `#` to `######` | Headings on the type scale; `h2` and `h3` feed `PageTableOfContents` |
| Paragraphs, `**strong**`, `*em*`, `<kbd>` | Body text at prose measure |
| `[link](url)` | A link; an external one opens in a new tab |
| `` `code` `` | Inline code |
| Fenced code | `CodeBlock`; a `mermaid` fence renders `MermaidDiagram` |
| Lists, `>` quotes, `---` | Lists, a quote, a rule |
| Tables | The `Table` of `@atom63/ui-react`, scrolling when wide |
