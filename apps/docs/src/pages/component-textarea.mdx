# Textarea

Textarea is the multi-line field: the same recessed chrome, focus ring and invalid edge as Input, around a native `<textarea>` that grows with its content up to a limit and then scrolls.

## When to use

Use Textarea for text that can run to several lines: notes, descriptions, messages. Use Input for one line. Pair it with a persistent label (`Field` and `FieldLabel`, or `aria-label` when the context names it).

## Props

| Prop | Default | What it does |
|------|---------|--------------|
| `size` | `md` | `sm`, `md` or `lg`: padding, type size and minimum height from the control ramp. |
| `variant` | `default` | `default`, `filled` or `plain`: the same field chrome as Input's `variant`, so a form's multi-line field matches its single-line ones. |
| `maxRows` | `12` | Rows the field grows to with its content before it scrolls. |
| `invalid` | `false` | Draws the danger edge and sets `aria-invalid`. Inside a Field, a rendered `FieldError` does the same. |
| `unstyled` | `false` | Drops the chrome so the textarea nests inside a parent that draws it. |
| `shadow` | `true` | `false` drops the recessed field shadow on flat or translucent surfaces. |
| `className` / `textareaClassName` | | Classes for the chrome wrapper and the native textarea. |

Every other prop goes to the native `<textarea>`.

## Inside an InputGroup

For a composer with actions above or below the text, use `InputGroupTextarea` in an `InputGroup`: the group draws the chrome and the textarea renders `unstyled`. Block addons stack above (`align="block-start"`) or below (`align="block-end"`) the text.

<DocExample
  align="left"
  title="Composer"

<InputGroup>
  <InputGroupTextarea aria-label="Message" placeholder="Write a message" />

    <Button size="sm">Send</Button>

</InputGroup>`}

## Decisions worth knowing

### Auto-grow stops at a limit

The field sizes to its content (`field-sizing: content`) from a minimum of one control height plus padding. Without a ceiling, pasted text would push a dialog's actions off the screen, so growth stops at `maxRows` and the text scrolls inside the field. A person can still drag the field taller, up to the same limit.

### A 16px floor on phones

On narrow viewports the type size never drops below 16px, so iOS Safari does not zoom the page when the field takes focus.
