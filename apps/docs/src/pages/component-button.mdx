# Button

Button is the reference action primitive for the current system: typed variants from `@atom63/ui-foundation`, Base UI-compatible rendering in `@atom63/ui-react`, and material values from the `control` and `action` contracts.

## Why it exists

Raw buttons are easy until they need to survive themes, density, loading, icon-only sizing, pressed states, and form safety. The shared Button exists so every product surface gets those decisions once.

## Contract shape

The root always renders `data-slot="button"` and carries `data-variant` and `data-size`. Trigger-specific composition can mirror a different slot through `data-trigger-slot`, while the anatomy stays a button.

| Layer | Examples |
|-------|----------|
| Public API | `variant`, `size`, `tone`, `shape`, `loading`, `disabled`, `render`, `type`. |
| Stable metadata | `data-slot="button"`, `data-size`, `data-variant`, `data-tone`, `data-loading`, `data-disabled`. |
| Local recipe vars | `--button-background`, `--button-foreground`, `--button-shadow`, `--button-radius`. |
| System vars | `--a63-action-*`, `--a63-control-*`, `--a63-density-scale`, `--a63-focus-ring`. |

## Sizes and icons

Each size step sets height, inline padding, gap and icon size together. Height, padding and gap are built on `--a63-space-unit`, so density scales them once (compact `md` is 28px, rounded to whole pixels); icon sizes stay the same. Icon-only buttons use the `icon-*` steps so the control stays square, and draw their glyph from `--a63-control-icon-only-size-*`, about 0.56 of the box (24/14, 28/16, 32/18). An icon beside a label stays on the smaller `--a63-control-icon-size-*` ramp. Button owns the icon gap — never add `mr-`/`ml-` margins to an icon inside one.

Hide decorative icons from assistive technology when the visible label already names the action.

## Emphasis without the accent

`default` is the neutral solid: high emphasis without the brand colour, such as a white play button on dark or a black Pay button. `primary` is the main action when the product's main action is in its brand colour. Use the accent for one or two cues per view; the main action may be neutral.

## Quiet secondary actions

Secondary actions in toolbars, list rows and card headers are ghost buttons with `tone="muted"`. The glyph and label rest in the secondary text colour and go to full contrast on hover, keyboard focus and press, so the row reads calm and the action still answers the pointer. Only `ghost` reads the tone; keep the main action at full contrast.

## Floating buttons

`raised` is a light button lifted off its ground: the panel fill, primary text and a soft shadow, with no border. With `shape="round"` at an icon size it is the floating button maps and light heroes use for back, locate and layers. Over a dark photo or video use `overlay` instead.

## Decisions worth knowing

### Button sets `type="button"`

I make the safe form behavior explicit. A shared Button should not accidentally submit a form because it was mounted inside one.

### Loading preserves layout

Loading hides the label visually and overlays a spinner rather than swapping content. That keeps button width stable and avoids a small but very noticeable layout jump.

<DocExample
  title="Loading and disabled"
  code={`<Button loading variant="primary">Save changes</Button>
<Button loading>Save changes</Button>
<Button disabled variant="primary">Save changes</Button>`}
>
  <div className="flex flex-wrap items-center justify-center gap-3">
    <Button loading variant="primary">
      Save changes
    </Button>
    <Button loading>Save changes</Button>
    <Button disabled variant="primary">
      Save changes
    </Button>
  </div>
</DocExample>

Compare the loading and resting buttons above: the label reserves its width, so the row never reflows when a request starts.

### Themes change material, not intent

Aqua adds gloss and tint through `--a63-control-gloss`, `--a63-control-highlight`, and `--a63-control-shadow`. Terminal can flatten those values. The Button recipe does not branch on `theme`; it consumes the same variables in every theme.
