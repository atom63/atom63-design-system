# Components

Components turn repeated interaction decisions into typed behavior, semantic structure, and theme-aware material without importing product assumptions. This catalog follows every `src/components/*` family exported from the root `@atom63/ui-react` entry. Layout, media, appearance, and provider APIs keep their existing pattern, theme, and architecture documentation instead of appearing here a second time.

**Stable** means a family has both a co-located representative story and focused test coverage. **Preview** identifies a concrete gap in that pair rather than making a broader maturity claim.
